
# Advanced CNNs and Transfer Learning

A Deep Learning project exploring CNN training strategies for image classification under limited data and computational resources. 
This project compares training from scratch, transfer learning, fine-tuning, data augmentation, and EfficientNet.

## Overview
This project evaluates different deep learning strategies using ResNet-18 and EfficientNet-B0 to classify images into 10 selected cat and dog breeds.

The experiments investigate the impact of pretrained weights, trainable parameters, data augmentation, and fine-tuning on classification performance and training efficiency.

## Experiments
- **B1:** ResNet-18 From Scratch
- **B2:** Feature Extraction
- **B3:** Fine-Tuning
- **B4:** Data Augmentation
- **B5:** EfficientNet-B0

## Best Result
- **Model:** ResNet-18 (B4, without augmentation)
- **Test Macro F1:** 93.38%

## Technologies
Python, PyTorch, Torchvision, Scikit-learn, Matplotlib, Google Colab.

## Dataset
Oxford-IIIT Pet Dataset (10 selected breeds).
